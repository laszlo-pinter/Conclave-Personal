# Phase 1 Produktziel und Dokumentation

Datum: 2026-08-11

## Ziel

Phase 1 richtet die Dokumentation auf Conclave Personal aus:

- persoenliches Multi-Agent-Arbeitswerkzeug
- einzelne Nutzer statt Unternehmen
- Windows und Linux als gleichwertige Zielplattformen
- Desktop-first, lokale Datenhaltung, Provider-Agnostik
- keine DSGVO-/Enterprise-Produktpositionierung
